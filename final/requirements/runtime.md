# Local final-MVP runtime facts

- Desktop Chrome URL: http://127.0.0.1:3000/pack. Landing page: http://127.0.0.1:3000/.
- Both server adapters use the shared OPENAI_MODEL setting, default gpt-6-astra. Photo recognition returns an actual colored triangle mesh for every proposal. The suitcase and editor render the supplied geometry directly; generated rows show Astra 3D and a completed photo shows 3D mesh ready. The actual credential remains exclusively in the ignored server environment file. Browser tests must not request, receive, compare, or type the real credential. Server credential boundaries are checked with synthetic server-unit fixtures.
- The inventory starts with nine clearly labeled demo items. Load demo restores that collection. Reset trip opens a dialog; Clear session starts empty. The Add item control offers category templates. Selecting an inventory item opens Item name, Item size, and optional shape/rotation controls.
- Try a sample photo sends the bundled pump-bottle JPEG through the same real photo-analysis endpoint as uploads. The fixture is public/fixtures/pump-bottle.jpg and depicts one pump bottle. The live positive photo-to-inventory flow is the primary browser check; missing-configuration behavior is separately covered by server unit tests.
- Ask Astra opens a dialog. The trip textarea is followed by Ask Astra. The resulting dialog shows full Bring along and Leave behind lists, a fit preview, Keep my current list, and Apply selection. Closing the dialog leaves the current selection unchanged. After inventory geometry/inclusion changes, reopening the dialog cannot show its old advice as current.
- Every inventory row has an Include checkbox and a Pin/Unpin control. Pinned essentials stay included. The item editor also exposes Essential item.
- Suitcase preset offers The weekender (cabin), The light traveler (personal, smallest), and The long escape (checked, largest). The personal bag with the full demo inventory is a repeatable overflow input. Make room offers verified swaps and Choose this swap applies one; Leave out is an explicit alternative. An unavailable swap never proves mathematical impossibility.
- Import collection accepts the bundled public/example-collection.json (step2 centimeter/Y-up format) and native millimeter/Z-up inventories. Native exports include units mm and upAxis z. The original sources and final do not share local browser storage; final uses its own IndexedDB database.
- Save packing plan downloads knapsack-final-plan.json and confirms it in the workspace. Its structural correspondence and reimport behavior are direct-test responsibilities; the browser run should verify the observable download flow without inventing file-inspection capabilities.
